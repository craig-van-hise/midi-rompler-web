# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
A critical polyphony bug exists where lifting a single key triggers a global release of all active voices across both the `Tone.Sampler` and `smplr` instruments. The objective is to patch the `AudioEngine` and MIDI event listeners to ensure strict **Per-Voice Release Tracking**. The release command must explicitly target the lifted note string/number to prevent the engine from defaulting to a global release state.

## 2. Technical Decisions & Dependencies
* **Tone.js Note Targeting:** Calling `triggerRelease()` without arguments kills all notes. It MUST be called as `triggerRelease(note)`.
* **smplr Note Targeting:** The smplr stop method MUST be explicitly passed the note: `stop({ note: note })`.
* **MIDI Velocity 0 Handling:** Some MIDI controllers send a `noteOn` event with `velocity: 0` instead of a dedicated `noteOff` event. The agent must ensure `velocity 0` is routed to the `releaseNote` pipeline with the correct note ID.
