# Product Requirements Prompt (PRP) — ✅ Completed

## 1. Project Context & Objectives
The user requires internal gain staging (trim) applied to specific instruments to balance the mix before the signal reaches the UI-controlled Master Volume. Additionally, the custom `LoopedSampler` handling the Strings patch must be updated to respect MIDI velocity, as it currently triggers all notes at maximum amplitude. 

## 2. Technical Decisions & Dependencies
* **Internal Trim Node:** We will insert a `Tone.Gain` node (`this.internalTrim`) directly before `this.panVol`. This mathematically scales the raw sample amplitude (where `1.0` is unity, `1.15` is +15%, and `1.35` is +35%).
* **Gain Map:**
  * `'electric-piano'`, `'vibraphone'`, `'strings'`, `'celeste'` => `1.15`
  * `'harp'` => `1.35`
  * All others => `1.0`
* **Velocity Routing:** The `LoopedSampler.triggerAttack` method will be updated to accept a normalized `velocity` argument (0.0 to 1.0) and pass it directly to `env.triggerAttack(Tone.now(), velocity)`.
