# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
The previous URL provided for the Strings asset resulted in a 404 because the `midi-js-soundfonts` CDN hosts audio as Base64-encoded strings inside JS files, not as raw `.ogg` endpoints. The objective is to finalize the Strings patch by programmatically fetching the CDN's `.js` file, extracting the C4 audio data via Regex, and passing it into the `LoopedSampler`. Additionally, the `LoopedSampler` must apply dynamic `loopStart` and `loopEnd` boundaries to create a seamless infinite sustain without audio clicks.

## 2. Technical Decisions & Dependencies
* **Target CDN:** `https://gleitz.github.io/midi-js-soundfonts/MusyngKite/string_ensemble_1-ogg.js`
* **Data Extraction:** Fetch the file as text and use `/\"C4\":\\s*\"(data:audio\\/ogg;base64,[^\"]+)\"/` to extract the Base64 Data URI.
* **Loop Trimming:** Standard samples have attack swells and decay tails that click when looped. The `Tone.Player` must have its loop boundaries set to 20% (start) and 80% (end) of the buffer's duration to isolate the steady sustain phase.

### Phase 1: Regex Extraction & Engine Routing — ✅ Completed
* **Objective:** Update `loadInstrument` to fetch and parse the Base64 string sample.
* **Instructions:**
    1. Open `src/audio/engine.ts`.
    2. Locate the `'strings'` condition inside the `loadInstrument` method.
    3. Replace the entire `'strings'` block with the following exact logic:
       ```typescript
       if (instrument === 'strings') {
           try {
               // 1. Fetch the Base64 JS payload from the CDN
               const response = await fetch('[https://gleitz.github.io/midi-js-soundfonts/MusyngKite/string_ensemble_1-ogg.js](https://gleitz.github.io/midi-js-soundfonts/MusyngKite/string_ensemble_1-ogg.js)');
               const text = await response.text();
               
               // 2. Extract the C4 Data URI
               const match = text.match(/"C4":\s*"(data:audio\/ogg;base64,[^"]+)"/);
               if (!match || !match[1]) {
                   throw new Error("Failed to parse C4 Base64 data from soundfont.");
               }
               const dataUri = match[1];
               
               // 3. Initialize LoopedSampler with the raw Data URI and an empty baseUrl
               const loopedSampler = new LoopedSampler({ 'C4': dataUri }, '');
               
               await loopedSampler.load();
               this.sampler = loopedSampler;
               this.sampler.output.connect(this.panVol);
           } catch (err) {
               console.error("String sample failed to load:", err);
               throw err; 
           }
           return;
       }
       ```
