# Product Requirements Prompt (PRP) — ✅ Completed

## 1. Project Context & Objectives
The MIDI Rompler utilizes multiple open-source audio CDNs and sample libraries to function without local asset bloat. The objective is to update the "Info" modal UI in `App.tsx` to provide proper attribution and outbound links to the creators and maintainers of these libraries.

## 2. Technical Decisions & Dependencies
* **Target Component:** `src/App.tsx` (Specifically the JSX block rendered when `infoOpen === true`).
* **Styling constraints:** The attribution must match the existing dark, skeuomorphic, terminal-inspired aesthetic. Links must use `target="_blank"` and `rel="noopener noreferrer"` for security.
* **Attribution Map:**
  1. **nbrosowsky/tonejs-instruments:** Acoustic Piano, Guitar, Bass.
  2. **smplr (danigb):** Electric Piano, Harp, Vibraphone, Celeste.
  3. **gleitz/midi-js-soundfonts:** Strings (MusyngKite).
