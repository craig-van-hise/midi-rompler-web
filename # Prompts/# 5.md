# Product Requirements Prompt (PRP) — 🔵 Active

## 1. Project Context & Objectives
The recent integration of the `smplr` library for the Electric Piano was successful. The objective now is to expand the Rompler's patch list to include Harp, Vibraphone, Strings, and Celeste. Since `smplr` provides a robust, CDN-hosted Soundfont architecture, we will route all four of these new instruments through the exact same `smplr` instantiation logic we built for the Electric Piano.

## 2. Technical Decisions & Dependencies
* **Engine:** We will continue using the `Soundfont` class from the `smplr` library for these new patches.
* **Internal Routing Map:** The `AudioEngine` must map the UI-facing instrument keys to their corresponding `smplr` CDN identifiers:
    * `'harp'` => `'orchestral_harp'`
    * `'vibraphone'` => `'vibraphone'`
    * `'strings'` => `'string_ensemble_1'`
    * `'celeste'` => `'celesta'`
* **UI Expansion:** The `App.tsx` instrument selection UI must be updated to include these new patch options so the user can select them.
