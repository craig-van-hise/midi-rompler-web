# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
The previous implementation of the `LoopedSampler` correctly established the engine architecture for infinite sustain, but utilized a temporary, incorrect placeholder asset (a Casio synth blip) and incorrectly halted execution to wait for human asset sourcing. The objective is to finalize the Strings patch by hardcoding a specific, high-quality, CORS-enabled `.ogg` string sample URL directly into the engine.

## 2. Technical Decisions & Dependencies
* **Target Asset:** We will utilize the MusyngKite soundfont repository for a rich string ensemble sample.
* **Exact URL:** `https://gleitz.github.io/midi-js-soundfonts/MusyngKite/string_ensemble_1-ogg/C4.ogg`
* **Format:** The `.ogg` format is strictly required here as it does not encode the micro-milliseconds of silence padding found in `.mp3` files, allowing `player.loop = true` to function seamlessly.
