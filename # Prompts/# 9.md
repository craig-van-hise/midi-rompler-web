# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
The previous implementation of the `LoopedSampler` incorrectly hardcoded local file paths (`/samples/strings/`), causing 404 errors and freezing the web app. The objective is to refactor the `LoopedSampler` instantiation to fetch its audio buffer from an absolute, external web URL, ensuring the application remains a lightweight, zero-local-asset web app.

## 2. Technical Decisions & Dependencies
* **Asset Sourcing:** The `LoopedSampler` will fetch audio from an external CDN/URL. 
* **Tone.js URL Handling:** When passing absolute URLs to `Tone.ToneAudioBuffers`, the `baseUrl` parameter must be omitted or set to an empty string.

## 3. Implementation Phases
