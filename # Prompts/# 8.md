# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
The user strictly requires sample-based instruments for sustained patches (like Strings) with infinite looping, rejecting synthesized approximations. The default `Tone.Sampler` does not natively support infinite buffer looping with release envelopes. The objective is to build a custom `LoopedSampler` class within the audio engine that perfectly mimics 80s hardware samplers: it loads raw `.wav` or `.ogg` buffers, dynamically calculates pitch-shifting playback rates based on a root note, flags the buffers to loop infinitely, and routes them through independent amplitude envelopes for true voice-independent polyphony.

## 2. Technical Decisions & Dependencies
* **Engine Architecture:** The worker agent will create a `LoopedSampler` class directly in `engine.ts`.
* **Pitch Shifting Math:** To emulate hardware samplers, the engine will find the nearest loaded sample buffer, calculate the MIDI interval difference, and apply varispeed pitch shifting using the formula: `playbackRate = Math.pow(2, interval / 12)`.
* **Polyphonic Voice Allocation:** Every triggered note will spawn a new `Tone.Player` and `Tone.AmplitudeEnvelope`. These will be stored in an `activeVoices` Map. Upon `triggerRelease`, the envelope's release phase is triggered, and the nodes are scheduled for garbage collection.
* **File Format Constraint:** The user MUST provide `.wav` or `.ogg` files. MP3s cannot be used for this phase, as their encoding pads the file with silence, causing audible clicks on the loop boundary.

    3. **Implement the following exact architecture:**
        ```typescript
        class LoopedSampler {
            buffers: Tone.ToneAudioBuffers;
            output: Tone.Volume;
            activeVoices: Map<string | number, { player: Tone.Player, env: Tone.AmplitudeEnvelope }>;
            envelope: { attack: number, decay: number, sustain: number, release: number };

            constructor(urls: Record<string, string>, baseUrl: string, onload: () => void) {
                this.output = new Tone.Volume(0);
                this.activeVoices = new Map();
                this.envelope = { attack: 0.1, decay: 0.1, sustain: 1.0, release: 1.0 };
                this.buffers = new Tone.ToneAudioBuffers(urls, onload, baseUrl);
            }

            triggerAttack(note: string | number) {
                if (this.activeVoices.has(note)) return; // prevent re-triggering active note
                
                // Assume root note is C4 for the string sample (Adjust if the user maps multiple)
                const rootNote = Tone.Frequency('C4').toMidi(); 
                const targetNote = Tone.Frequency(note).toMidi();
                const interval = targetNote - rootNote;
                
                const buffer = this.buffers.get('C4'); // Get the root buffer
                if (!buffer) return;

                const player = new Tone.Player(buffer);
                player.loop = true; // INFINITE SUSTAIN
                player.playbackRate = Math.pow(2, interval / 12); // Varispeed pitch shift
                
                const env = new Tone.AmplitudeEnvelope(this.envelope);
                player.connect(env);
                env.connect(this.output);
                
                this.activeVoices.set(note, { player, env });
                
                player.start();
                env.triggerAttack();
            }

            triggerRelease(note: string | number) {
                const voice = this.activeVoices.get(note);
                if (!voice) return;
                
                voice.env.triggerRelease();
                this.activeVoices.delete(note);
                
                // Garbage collect after release phase
                setTimeout(() => {
                    voice.player.dispose();
                    voice.env.dispose();
                }, (this.envelope.release + 0.1) * 1000);
            }
            
            // Allow dynamic ADSR updates
            set(params: { envelope?: Partial<typeof this.envelope> }) {
                if (params.envelope) {
                    this.envelope = { ...this.envelope, ...params.envelope };
                }
            }
        }
        ```
