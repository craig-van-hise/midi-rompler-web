# Product Requirements Prompt (PRP) — 🔵 Active

## 1. Project Context & Objectives
The recent polyphony fix was successfully applied to the `Tone.Sampler` (Acoustic Piano) but failed for all `smplr` instruments (Electric Piano, Strings, Harp, Vibraphone, Celeste). Lifting a single key on a `smplr` patch still triggers a global release. This is caused by an incorrect argument signature being passed to the `smplr` `.stop()` method. The objective is to patch `engine.ts` to ensure universal, voice-independent release across all instruments by passing the primitive note value correctly.

## 2. Technical Decisions & Dependencies
* **API Correction:** The `smplr` library's `stop()` method expects a primitive string or number (`sampler.stop('C4')`), NOT an object (`sampler.stop({ note: 'C4' })`).
* **Universal Note Passing:** The `releaseNote` function must accept a single `note` argument (string or number) and pass it directly to the respective release method of whichever engine is currently active.
