# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
The user requires a frictionless, state-persistent application. The objectives are:
1. **Persistence:** Save all UI parameters (Instrument, Volume, Pan, ADSR, Reverb, Tuning, MIDI Channel, and MIDI Input Port) to `localStorage` so the Rompler reboots exactly as it was left.
2. **OMNI MIDI Routing:** Add an "OMNI" option to the MIDI input dropdown that listens to all available connected MIDI devices simultaneously. If a previously saved specific port is disconnected, the app must gracefully fallback to OMNI.
3. **Auto-Power Architecture:** Default the Power state to ON without violating browser Autoplay policies by utilizing a Global DOM Interaction Trap.

## 2. Technical Decisions & Dependencies
* **Persistence Hook:** Implement a custom React hook `usePersistentState<T>(key: string, initialValue: T)` to cleanly wrap `useState` with `localStorage` read/write capabilities.
* **OMNI Implementation:** In the Web MIDI API handler, if `selectedInputId === 'OMNI'`, iterate over all `midiAccess.inputs.values()` and attach the `onmidimessage` listener to every port.
* **Auto-Start Trap:** Use `window.addEventListener('pointerdown', initAudio, { once: true })` and `window.addEventListener('keydown', initAudio, { once: true })` to bootstrap `Tone.start()` on the first human interaction with the DOM.

### Phase 1: The `usePersistentState` Hook & App Refactor — ✅ Completed
* **Objective:** Create the utility hook and convert all standard `useState` parameters in `App.tsx` to persistent state.
* **Instructions:**
    1. Create a new file (or add to an existing utils file): `src/lib/usePersistentState.ts`.
    2. Implement the hook:
       ```typescript
       import { useState, useEffect } from 'react';

       export function usePersistentState<T>(key: string, initialValue: T): [T, (value: T | ((val: T) => T)) => void] {
           const [state, setState] = useState<T>(() => {
               try {
                   const item = window.localStorage.getItem(key);
                   return item ? JSON.parse(item) : initialValue;
               } catch (error) {
                   console.error(`Error reading localStorage key "${key}":`, error);
                   return initialValue;
               }
           });

           useEffect(() => {
               try {
                   window.localStorage.setItem(key, JSON.stringify(state));
               } catch (error) {
                   console.error(`Error setting localStorage key "${key}":`, error);
               }
           }, [key, state]);

           return [state, setState];
       }
       ```

    4. Refactor all parameter states (instrument, volume, pan, reverbWet, tuningOffset, midiChannel, attack, decay, sustain, release) to use this hook. Ensure unique keys (e.g., `'rompler_instrument'`, `'rompler_attack'`).

### Phase 2: OMNI Routing & MIDI Fallback — ✅ Completed

* **Instructions:**
    1. Open `src/audio/useMidi.ts`.
    2. Ensure `selectedInputId` is also persisted (either pass it down from `App.tsx` using the new hook, or implement `localStorage` inside `useMidi`). Default it to `'OMNI'`.
    3. Inside the `useEffect` that handles MIDI input changes (where `onmidimessage` is attached), implement the OMNI logic:
       ```typescript
       // Clear previous listeners first...
       inputs.forEach(input => input.onmidimessage = null);

       if (selectedInputId === 'OMNI') {
           // Attach to ALL inputs
           inputs.forEach(input => input.onmidimessage = handleMidiMessage);
       } else {
           // Attach to specific input, with fallback validation
           const targetInput = inputs.find(i => i.id === selectedInputId);
           if (targetInput) {
               targetInput.onmidimessage = handleMidiMessage;
           } else if (inputs.length > 0) {
               // Fallback: Port not found. Force OMNI.
               console.warn(`Saved MIDI port ${selectedInputId} not found. Falling back to OMNI.`);
               setSelectedInputId('OMNI'); 
               inputs.forEach(input => input.onmidimessage = handleMidiMessage);
           }
       }
       ```
    4. Open `src/App.tsx` and ensure `<option value="OMNI">OMNI (All Ports)</option>` is the first choice in your MIDI device dropdown.

### Phase 3: Global Autoplay Trap — ✅ Completed
* **Objective:** Default Power to ON visually and bootstrap the audio engine silently on the first DOM interaction.
* **Instructions:**
    1. Open `src/App.tsx`.
    2. Set the initial power state to `true` (do NOT persist power state in `localStorage`, always default to `true` on load).
    3. Add a new `useEffect` hook to create the interaction trap:
       ```typescript
       useEffect(() => {
           const initTrap = async () => {
               if (!audioEngine.isInitialized && power) {
                   try {
                       await audioEngine.init();
                       // Engine is now awake and ready
                   } catch (err) {
                       console.error("Audio initialization failed:", err);
                   }
               }
           };

           // Listen for first interaction anywhere on the document
           window.addEventListener('pointerdown', initTrap, { once: true });
           window.addEventListener('keydown', initTrap, { once: true });

           return () => {
               window.removeEventListener('pointerdown', initTrap);
               window.removeEventListener('keydown', initTrap);
           };
       }, [power]);
       ```
    4. Ensure the UI Power Button still functions (if toggled off, it should bypass processing MIDI events).
